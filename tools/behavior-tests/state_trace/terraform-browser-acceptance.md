The first smoke uses the real remote asset manifest, installed parser and source
rates, an explicitly declared sixteen-by-sixteen world with seven nonempty owners,
and the actual local native worker. The preregistered seed enters the existing
Game.Start CLI path before world creation; the imported map bypasses generated-
map quickstart defaults. There is no public live Game RNG-state getter, so that
browser observation stays unsupported. All observer helpers retain their actual
`GLSMAC_data/tests` namespace; source and request bytes are fingerprinted before
launch. The fixture only observes native results, exposes actual widget points,
sets initial selection, focuses the owned destination and exits. Work and route
commands come solely from real pointer/keyboard input into production controls.

The smoke requires rendered nonblank HUD pixels before pointer input. It records
all 29 distinct menu action identities, source labels and actual row bounds;
checks all seven owners/cities/eight units and all 128 tiles before and after a
non-owned target click plus Escape and Tab; then clicks the actual owned base.
The rejected pointer's native hit reports empty versus foreign ownership rather
than guessing from a screen offset. Raw UI/native snapshots remain preserved;
only the declared native-only comparison excludes the separately asserted UI
subtree. Scalar receipt IDs/caller/data and native pending/lock state distinguish
accepted input from settlement. Actual SDL ingress and engine-dispatch records
must be enabled and complete. No handler invocation substitutes for work input.

manifest override; it must preserve all other installed fields and record both
installed and edited hashes. No original observation is edited or read for an
